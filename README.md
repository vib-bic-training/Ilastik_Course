# Software installation before the course
**Important**
If you have a KU Leuven PC, install both Ilastik and FIJI in `C:\GBW_MyPrograms`

## Ilastik installation
Follow the instructions here: https://www.ilastik.org/documentation/basics/installation
Install version 1.4.1 (Release 1.4.1.post1 (31. May 2025)). No GPU Necessary!

### Installation on Windows
1. Download the Windows self-extracting installer 
2. Copy the installer to `C:\GBW_MyDownloads` and run it (You will likely need admin rights for this).
3. Choose `C:\GBW_MyPrograms` to install the software. 
   
### Installation on Mac
1. Download the .tar.bz2 file for your version of OSX and extract its contents with a simple double-click.
2. Copy ilastik.app to the folder of your choice (usually your Applications folder)
3. Control-click the app icon and choose “Open” to begin (for more info, see https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unidentified-developer-mh40616/mac).

## FIJI installation
Follow the instructions here: https://fiji.sc/
<img width="734" height="571" alt="image" src="https://github.com/user-attachments/assets/56c9fe8e-8b06-49e3-bd6f-fcd9f9f8fb12" />

Install the latest stable version of FIJI in the `C:\GBW_MyPrograms` if the computer is a KU Leuven Windows PC.

### After installing FIJI:
1. Launch FIJI
2. Go to Help → Update...
3. Apply all updates and restart FIJI

## Installing Ilastik and Morpholibj plug-ins
Follow the instructions here: https://www.ilastik.org/documentation/fiji_export/plugin
*FIJI and Ilastik need to be already installed*

1. Open FIJI
2. Go to Help → Update...
3. Click Manage update sites
4. Enable the "ilastik" and "IJPB-Plugins" update sites
5. Apply changes and restart FIJI
6. We will configure the plug-in in the course to finalize the installation


## Test your installation

### Ilastik
- Launch Ilastik
- Open any example project or create a new Pixel Classification project

### FIJI
- Open FIJI
- Open an image (File → Open)
- Verify menus load correctly

### Plugin
- Check if Ilastik appears in the FIJI menus (Plugins → Ilastik)

**After installing all software, restart your computer.**
